Kibitzer · model card

Architecture

A causal sequence model for chess. Each board is encoded into a single token; a Llama-style trunk reads the game as a sequence and emits a move-policy and a value estimate.

Components

Board state
64 square tokens plus 7 auxiliary features encoding side to move, castling rights, en-passant file, and halfmove clock.
PositionEncoder
Embeds each square and fuses the auxiliary features into per-token vectors.
Bidirectional Square Encoder
Summarises all 64 squares of a board into a single timeline token per move.
Transformer trunk
Causal Llama-style stack: RMSNorm, rotary positional embeddings, SwiGLU MLPs, and PyTorch scaled dot-product attention over the sequence of board tokens.
Policy head
Predicts one of 4,672 AlphaZero-style moves, factored as 64 from-squares × 73 move types.
Value head
Bounded scalar outcome estimate via tanh in (-1, 1).
